# أرض النفط — النسخة الجماعية

لعبة جماعية تعمل من 2 إلى 10 قباطنة عبر عدة جوالات.

## التشغيل المحلي

```bash
npm install
npm start
```

ثم افتح: `http://localhost:3000`

## النشر على Render

أنشئ **Web Service** واربط المستودع، ثم استخدم:

- Build Command: `npm install`
- Start Command: `npm start`

هذه النسخة مخصصة للرفع المباشر عبر GitHub: ارفع جميع الملفات إلى واجهة المستودع الرئيسية، ولا تنشئ مجلد `public` ولا تنقل الملفات داخله.

أو دع Render يقرأ ملف `render.yaml` تلقائيًا.

## المزايا

- غرفة برمز وباركود وجهاز مستقل للمضيف.
- من 2 إلى 10 لاعبين بجوالات متعددة.
- بواخر وموارد وأرصدة ومهمات سرية خاصة بكل لاعب.
- مزاد سري متزامن على ست أراضٍ لمدة 30 ثانية، ويمكن شراء أكثر من أرض.
- خصم قيمة العرض فور تثبيته حتى لو لم يفز اللاعب بالأرض.
- شاشة مستقلة لكشف الأراضي والموارد قبل الانتقال للمهمة.
- تجديد المهمة السرية كل جولتين، ومكافآتها تشمل صندوقًا عشوائيًا.
- أسئلة غير مكررة يختار اللاعب مستوى صعوبتها.
- بيع وشراء بالكميات مع تحقق مركزي من الرصيد.
- صندوق عشوائي في السوق مقابل 2,000 ريال، وقد يكون فارغًا أو غنيًا بالموارد.
- مقايضات مباشرة بين اللاعبين وقبول أو رفض العروض.
- بورصة موارد ونسب ارتفاع وانخفاض عشرية.
- عرض واضح للمواد التي غلت أو رخصت في السوق.
- زر «إرسال الباخرة» يوقف اللعبة فور اكتمال الحمولة ويعلن الفائز.
- شاشة ختامية تعرض باخرة الفائز وتقدم جميع القباطنة ومواردهم.
- واجهة رئيسية لاختيار غرفة جديدة أو الدخول برمز أو مشاهدة شرح سريع.
- إعداد صعوبة قبل البدء: سهل بالمتطلبات الأساسية، وصعب بمتطلبات بواخر مضاعفة ×2.
- أسعار بداية الموارد والأسهم ونسب الحركة عشوائية في كل لعبة، وتتغير عشوائيًا بعد كل جولة.

## ملاحظة

الغرف تحفظ في ذاكرة الخادم لمدة ست ساعات. سجل الأسئلة المستعملة يُحفظ كذلك في متصفح المضيف ويرسل إلى الغرفة الجديدة لمنع إعادة الأسئلة في الألعاب اللاحقة على جهاز المضيف نفسه.
